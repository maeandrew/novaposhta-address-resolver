# Contributing

[English](CONTRIBUTING.md) · [Українська](CONTRIBUTING.uk.md)

This project welcomes focused pull requests that preserve the framework-free
core and its safety guarantees.

Before opening a pull request:

1. Read `AGENTS.md` and the implementation documents.
2. Add or update offline tests for behavior changes.
3. Keep vendor/framework integrations in their adapter package.
4. Run the formatter, static analysis, and the complete test suite.
5. Do not include credentials, customer data, live API responses, or private
   infrastructure details.

If an API or domain decision changes, update `docs/DECISIONS.md` and the
relevant README section in the same change.
