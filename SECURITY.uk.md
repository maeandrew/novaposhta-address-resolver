# Політика безпеки

[English](SECURITY.md) · [Українська](SECURITY.uk.md)

Не публікуйте security vulnerabilities у public issues. Надішліть приватний
звіт maintainer-у із:

- package і version;
- мінімальним відтворенням без personal data;
- описом impact і відомим mitigation.

Ніколи не додавайте API keys, production payloads, customer names, phone
numbers або повні адреси. Усі reproductions треба redacted перед надсиланням.
